FIGURE 1. TITLE: "PPO WITH AN ACCUMULATING LINEAR CRITIC".
LAYOUT: TWO CLEAR HORIZONTAL LANES WITH A SHARED INPUT AT LEFT AND PPO UPDATE AT RIGHT.
TOP LANE: "MATH QUESTIONS" → BLUE BOX "CURRENT ACTOR" / "GENERATE FRESH ANSWERS" → BOX "FRESH TOKEN TRAJECTORIES". FROM THIS TRAJECTORY BOX BRANCH RIGHT TO "MATH-VERIFY" / "FINAL ANSWER SCORING". THAT SCORER OUTPUTS "TERMINAL REWARD: 0 OR 1" / "EARLIER REWARDS: 0".
LOWER LANE: BRANCH THE FRESH TRAJECTORIES DOWN INTO TEAL BOX "FROZEN BASE ENCODER" / "CAUSAL PREFIX FEATURES". INSIDE A SMALL LABEL "TWO-THIRDS OR FINAL LAYER". CONNECT THIS TO AMBER BOX "ACCUMULATED CRITIC STATISTICS" / "TWO FIXED QUESTION FOLDS" / "LSTD(0.95), LSTD(0.99), OR RIDGE". SEND TERMINAL REWARDS FROM SCORER INTO THIS STATISTICS BOX AS A SEPARATE CLEAR ARROW. STATISTICS → AMBER BOX "LINEAR SOLVES" / "ONE HEAD PER FOLD" → BOX "CROSS-FITTED PREFIX VALUES". ALSO SEND PREFIX FEATURES DIRECTLY TO THE PREFIX VALUES BOX TO INDICATE EVALUATING THE FITTED HEADS.
RIGHT SIDE: PREFIX VALUES AND REWARDS BOTH ENTER PURPLE BOX "GAE" / "GAMMA = 1; GAE LAMBDA = 0.95". GAE → "TOKEN ADVANTAGES" → PURPLE BOX "CLIPPED PPO UPDATE". FRESH TRAJECTORIES ALSO CONNECT TO PPO UPDATE VIA AN OUTER TOP ROUTE LABELLED "FRESH ACTIONS AND OLD LOG-PROBABILITIES". ONE BLUE RETURN ARROW FROM PPO UPDATE TO CURRENT ACTOR LABELLED "UPDATE ACTOR PARAMETERS".
ADD TWO COMPACT FOOTNOTES ALONG BOTTOM: "ENCODER FIXED; CRITIC WEIGHTS REFITTED EACH UPDATE." AND "HISTORICAL DATA ENTERS CRITIC STATISTICS; PPO ACTOR UPDATES USE FRESH DATA ONLY."
NO ARROW FROM PPO UPDATE TO THE ENCODER. NO REPLAY BUFFER. NO FUTURE-TOKEN INPUT TO PREFIX FEATURES. THE LAYER CHOICES AND CRITIC METHODS ARE ALTERNATIVE EXPERIMENTAL CONDITIONS, NOT SIMULTANEOUS ENSEMBLES.

FIGURE 2. TITLE: "CROSS-FITTED LSTD: FROM TOKEN TRANSITIONS TO PPO".
THREE WELL-SEPARATED PANELS LEFT TO RIGHT, LABELLED "A. CAUSAL TRANSITIONS", "B. PERSISTENT QUESTION FOLDS", "C. ADVANTAGES AND ACTOR UPDATE".
PANEL A: SHOW THREE PREFIX CARDS "QUESTION", "QUESTION + TOKEN 1", "QUESTION + TOKENS 1–2", FOLLOWED BY SMALL "TERMINAL" CARD. ARROWS BETWEEN THEM LABELLED "TOKEN 1", "TOKEN 2", "TOKEN 3". BELOW THEIR ARROWS RESPECTIVELY LABEL REWARDS "0", "0", "R". A FOOTNOTE DEFINES "R = 1 IF CORRECT, ELSE 0". THE THREE PREFIX CARDS CONNECT DOWN TO A SINGLE TEAL "FROZEN ENCODER" BAR, THEN TO THREE AMBER FEATURE LABELS "X0", "X1", "X2". LABEL "VALUE BEFORE EACH ACTION". TERMINAL FEATURE LABEL "X3 = 0". SHOW ONE COMPACT BOX "TRACE: ZT = XT + LAMBDA × Z(T−1)" AND "TRACE RESETS FOR EACH ANSWER". DO NOT DRAW FINAL OUTCOME AS AN INPUT TO THE ENCODER.
PANEL B: SHOW TWO VERTICALLY STACKED INDEPENDENT TRAINING ROWS. TOP "GROUP A TRANSITIONS" → "ACCUMULATE A_A, B_A" → "SOLVE W_A" → "VALUES FOR GROUP B". BOTTOM "GROUP B TRANSITIONS" → "ACCUMULATE A_B, B_B" → "SOLVE W_B" → "VALUES FOR GROUP A". USE LARGE CLEAR TYPE AND KEEP ROWS SEPARATE; NO CROSSING ARROWS NEEDED. SMALL TEXT ABOVE: "QUESTION ASSIGNMENTS STAY FIXED". BELOW ADD "ALL ANSWERS TO ONE QUESTION STAY IN ONE GROUP". THEN A COMPACT EQUATION BOX WITH EXACT LINES:
"A ← A + ZT [XT − X(T+1)]ᵀ"
"B ← B + ZT RT"
"W = SOLVE(A + 0.01 I, B)"
AND SMALL NOTE "GAMMA = 1; LSTD LAMBDA = 0.95 OR 0.99".
ANOTHER SMALL NOTE: "MATRICES PERSIST ACROSS PPO UPDATES; NO COUNT NORMALIZATION."
PANEL C: BOX "FRESH PREFIX VALUES" RECEIVES OUTPUTS OF BOTH CROSS-FITTED ROWS. SHOW "VALUE = Wᵀ X". BELOW SHOW BOX "TD ERROR" WITH "DELTA = REWARD + NEXT VALUE − VALUE". NEXT BOX "GAE" / "BACKWARD ACCUMULATION; LAMBDA = 0.95". NEXT "TOKEN ADVANTAGES" → "CLIPPED PPO UPDATE" → "UPDATED ACTOR". A SEPARATE SMALL LABEL CONNECTS TO TD ERROR "FRESH REWARDS". DO NOT SHOW BACKPROP THROUGH THE FROZEN ENCODER OR THE LINEAR SOLVE.
BOTTOM FOOTNOTE ACROSS CANVAS: "CROSS-FITTING EXCLUDES EACH QUESTION'S OWN OUTCOMES FROM ITS CRITIC FIT; ACCUMULATED DATA STILL COMES FROM HISTORICAL POLICIES."
